# Kelly et al. 2023 — local leakage-safe reproduction

This runner adapts *Blood biomarker-based classification study for neurodegenerative diseases* (Scientific Reports, 2023) to the three thesis pairwise tasks.

## Implemented paper matrix

The paper evaluates five feature representations with five classical classifiers:

- feature representations: `all_genes`, `knowledge_genes`, `vssrfe_lr`, `lasso`, `vae_latent`;
- classifiers: `lr`, `svm`, `xgboost`, `rf`, `mlp`.

That is 25 classical configurations. `--include-deep` adds the paper's two standalone all-gene models, `vae_classifier` and `cnn`, for 27 configurations total. Deep models are deliberately not crossed with the five feature representations; `--deep-feature-models` is rejected because that experiment is not in the paper.

LASSO, VSSRFE model selection, and classifier tuning optimize average precision (PR-AUC) with train-only cross-validation. VSSRFE is refit inside each validation fold instead of selecting features on the full training matrix before CV, which was a double-dipping bug in the released code.

## Knowledge feature set

`knowledge_genes` is the union of:

- the top 3,000 median-absolute-deviation genes computed on `train_inner` only;
- curated genes supplied with `--knowledge-genes-file`.

The authors' exact `prev_features.txt` is absent from the public repository. Without a supplied curated list the configuration is skipped and marked `skipped_missing_curated_knowledge_list`. The explicitly opted-in `--allow-incomplete-knowledge` sensitivity run uses only the top-MAD genes, is named `mad_top3000_only`, and must not be described as an exact knowledge-set reproduction.

## VAE profiles

`--implementation-profile paper` uses the article's reported VAE-feature learning rate (`1e-5`). `public_code` uses the released AD script value (`1e-4`). Both use 1,000 epochs, patience 10, and categorical cross-entropy by default. The published implementation has stochastic `mu/sigma` sampling but no KL term; this is recorded in each feature manifest rather than silently presenting it as a conventional KL-regularized VAE.

The standalone model called “VAE classifier” by the paper is reproduced as its released deterministic 4096-1024-512-128-128-64 dense classifier. It is not the latent autoencoder used as a feature representation.

## TxT shared-test command for one task

Use a canonical directory containing `seed_101.csv` through `seed_110.csv` generated by `SOTA/source/shared_test_splits.py`. The manifests are created on the shared multiclass cohort and filtered by sample ID, so every method and task uses identical 70/10/20 membership.

```powershell
python SOTA\source\nature-2023\run_experiments.py `
  --x-file task_dataset\processed\txt_pairwise_multitask\ad_vs_mci\X.csv `
  --y-file task_dataset\processed\txt_pairwise_multitask\ad_vs_mci\y.csv `
  --split-manifest-dir <canonical-70-10-20-splits> `
  --result-root results\SOTA_reproduction\nature-2023\ad_vs_mci `
  --protocol batch_holdout `
  --batch-scenarios shared_test `
  --repeats 10 `
  --feature-sets knowledge_genes vssrfe_lr lasso vae_latent `
  --models lr svm xgboost rf mlp `
  --implementation-profile paper `
  --hyperparameter-mode fixed_paper `
  --artifact-scope train_inner `
  --threshold-mode fixed_0_5
```

The shared benchmark deliberately excludes direct all-gene inputs and uses `--hyperparameter-mode fixed_paper`. Those parameters were optimized for the paper's AD-vs-control dataset; on AD-vs-MCI and MCI-vs-control this is a declared transferred paper profile, not task-specific tuning. Re-running the full 100/200-iteration nested Bayesian searches for every one of the 30 shared-test splits is available in the low-level runner, but is not the primary reproduction command.

The primary shared benchmark runs the same 4096-1024-512-128 VAE architecture,
loss, optimizer, learning rate, batch size and early-stopping rule in an isolated
PyTorch CUDA worker (`--vae-backend torch --vae-device cuda`). This avoids the
multi-hour CPU-only TensorFlow path on native Windows. The manifest records the
backend, CUDA device, PyTorch version, parameter count, epochs actually trained,
best loss and elapsed time. TensorFlow remains available through the low-level
runner for framework-exact sensitivity checks.

## Verification

```powershell
python SOTA\source\nature-2023\test_nature2023_reproduction.py
python SOTA\source\nature-2023\run_experiments.py --smoke --feature-sets all_genes --models lr
```

The local three-task experiment is a method-level extension: Kelly et al. evaluated AD-vs-control and PD-vs-control, not AD-vs-MCI or MCI-vs-control.
